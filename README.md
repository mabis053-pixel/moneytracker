# MoneyTracker GitHub Pages
Aplikasi pencatatan keuangan berbasis HTML/CSS/JavaScript.

## Fitur
Dashboard, pemasukan, pengeluaran, kategori, laporan, ekspor CSV, cetak, backup/restore JSON, dan PWA.

## Deploy
Upload semua file ke repository GitHub. Lalu **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
Alamat menjadi `https://USERNAME.github.io/NAMA-REPO/`.

## Catatan
Versi ini sengaja dibuat tanpa PHP/MySQL agar dapat berjalan langsung di GitHub Pages. Data disimpan pada browser (localStorage), sehingga belum tersinkron antar perangkat/pengguna.
